One tag to show a verified Zcash payment

This is how a shop, an exchange support desk or a grant program can check a customer's receipt on its own site. The proof is verified in the visitor's browser. Your server never sees the receipt, and the customer's wallet stays private.

<script type="module" src="/zceipt/widget.js"></script>
<zcash-receipt receipt="zip311r1…"
               expect-address="utest1…your address…"
               min-zatoshis="1000000"></zcash-receipt>

Kemi's Coffee · order #42

2 × flat white · 0.01 ZEC (testnet)
Waiting for the customer's receipt…

The element fires receipt-verified or receipt-invalid, so the page can mark the order paid:

document.querySelector("zcash-receipt").addEventListener("receipt-verified", (e) => markPaid(e.detail));

For servers and scripts, use the same package without the UI: import { verifyReceipt } from "zceipt".
