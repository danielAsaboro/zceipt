Sign in with Zcash

        
Prove control of a shielded address with no transaction. Issue a one-time challenge, the user runs the command in their wallet, then paste the zsig1… it prints.

        
        
        

        
        
        

      

      
How it works
The wallet makes a Halo 2 proof that it can spend a fresh note to the address, and signs the domain and nonce with the proof's randomized key. A sign-in made for another site, or replayed, is refused. Nothing else about the wallet is revealed.
